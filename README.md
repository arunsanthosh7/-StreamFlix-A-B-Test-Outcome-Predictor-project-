# -StreamFlix-A-B-Test-Outcome-Predictor-project-
Built a Bayesian A/B test prediction system for a Netflix-style streaming service using Beta-Binomial inference on 10,000 users across 12 experiments. Achieved 43% faster decisions and saved ~3 weeks per test vs. traditional p&lt;0.05 methods. Tools: Python, Pandas, SciPy, Matplotlib.
